# 思维导图页面高保真原型设计方案 (v6.0)

本设计文档总结了在 `v6.0` 迭代中，对思维导图高保真原型页面的优化设计，重点复刻右侧侧边栏、精细调节浮动弹窗与底部工具栏的间隙、精简顶部栏并修复导航面包屑，提升交互真实感。

---

## 1. 调整与优化内容

### 1.1 底部工具栏布局切换间隙调整
*   **定位优化**：继续采用 `position: fixed` 的视口定位方案（即方案 A）。
*   **空隙精简**：将布局切换弹窗 `layoutDropdown` 垂直计算位置的偏移值由原先的 `- 8px` 缩小为 `- 2px`，实现与“关于导图”弹窗类似且更加精致紧凑的非重叠悬浮间隙（计算方式：`rect.top - layoutDropdown.offsetHeight - 2`）。

### 1.2 顶部操作栏与面包屑路径修正
*   **书签按钮移除**：彻底删除 breadcrumb-bar 中“书签”按钮（Ribbon）。
*   **收藏星星高亮**：将“收藏”按钮 SVG 星星设置为实心高亮金黄色（`#e0a92e`）。
*   **主页路径指示**：在 `AI配音` 文本前添加一个“房子”外形的主页 SVG 图标，展示为 `🏠 AI配音` 样式的层级节点路径，与设计图保持高度统一。

### 1.3 右侧侧边栏（Right Sidebar）深度高保真复刻
*   **侧边栏头部**：
    *   “节点笔记”左侧图标更换为斜向的纸飞机（Send）SVG 图标。
    *   右侧操作按钮保持 `</>` (代码视图)、`<` (上一个兄弟节点)、`>` (下一个兄弟节点)、`...` (更多) 顺序。
    *   **兄弟节点笔记切换逻辑**：点击 `<` 和 `>` 按钮，能够智能获取当前选中节点的所有同级（兄弟）节点，并在兄弟节点之间进行循环轮转切换，同步在侧边栏中加载该兄弟节点的名称及对应笔记内容。
*   **Markdown 编辑工具栏**：
    *   按截图排版为两行，并新增各功能区之间的分割线（`|`）：
        *   第一行：`H`、`B`、`I`、`S`（加带删除线样式的 CSS）、`链接` | `无序列表`、`有序列表`、`任务列表` | `引用`（改为纸飞机图标）、`分割线`（改为减号）。
        *   第二行：`代码块`（`</>`）、`行内代码`（`< >`） | `云上传`、`表格` | `撤销`、`重做`。
*   **侧边栏垂直标签页（Tab Bar）**：
    *   **激活状态样式**：激活的标签页背景改为 solid 深蓝色（`#1862c6`），图标颜色改为纯白色，其他未激活标签页为透明背景及淡金色 hover。
    *   **第三个“主题”标签页**：图标更换为斜向的图钉（Pin）SVG 图标。
    *   **第五个“节点图标”标签页**：图标更换为笑脸（Smiley Face）SVG 图标。
*   **第四个“样式与配置”标签页扩展**：
    *   **画布背景配置**：提供 4 种暗色预设色块（经典漆黑、深空灰蓝、密林暗绿、紫幻魅影）加 1 个自定义 HTML 颜色选择器。
    *   **网格颜色配置**：提供 4 种网格色块（半透明白、浅柔金、冰爽蓝、霓虹红）加 1 个自定义 HTML 网格颜色选择器。
    *   点击色块或选择颜色后，主画布的背景和网格颜色实时切换更新。

## 2. 详细交互设计与逻辑实现

### 2.1 兄弟节点导航算法
在侧边栏头部，点击 `<` 和 `>` 时：
1. 寻找当前激活的节点 `.tree-node.active`。
2. 找到其最近的同级节点：通过遍历其父级分支 `tree-branch` 容器的兄弟分支，或者直接查找在画布 DOM 中同层级的 `.tree-node` 节点。
3. 如果存在多个兄弟节点，计算当前节点的索引 `idx`。
4. 点击 `<` 时，切换至 `(idx - 1 + length) % length`；点击 `>` 时，切换至 `(idx + 1) % length`。
5. 自动触发新节点的 `selectNode(targetEl)`，高亮该节点并动态更新文本域中的 Markdown 内容。

### 2.2 画布与网格颜色动态应用
1. 画布背景色直接绑定至 `--bg0` 自定义 CSS 变量。
2. 网格线颜色绑定至 `--grid-color` 自定义 CSS 变量。
3. 当选择预设色块或自定义颜色选择器时，通过 `document.documentElement.style.setProperty` 实时修改属性，网格重绘引擎自动适应，无需刷新页面。
