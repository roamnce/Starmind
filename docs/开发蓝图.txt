## 项目开发蓝图

### 1. 项目目标
构建一个类似 **MarginNote** 的跨平台知识管理软件，支持 **Windows** 和 **Android 平板**。核心能力：
- PDF 阅读与批注（手写、文字注释）
- 网页阅读与文本摘录
- 框选摘录（文字/截图）
- 笔记卡片与双向联动
- 思维导图/大纲组织
- 间隔复习与全文搜索

### 2. 技术栈定案
- **前端 UI**：Flutter (Dart)
- **核心引擎**：Rust，负责 PDF 解析、数据存储、搜索、业务逻辑
- **桥接方式**：`flutter_rust_bridge` 自动生成 Dart ↔ Rust FFI 胶水代码
- **状态管理**：Riverpod (Flutter)
- **持久化**：SQLite (通过 Rust 的 `rusqlite` 操作)
- **PDF 解析**：`pdfium-render` (Rust 绑定)，提取字符级文本块、路径、图片，支持区域位图渲染
- **全文搜索**：`tantivy` (Rust)
- **网页渲染**：`webview_flutter` (Flutter)，通过 JS 通道提取选中文本
- **手写平滑**：`perfect_freehand` 算法 (Dart 实现)
- **数据序列化**：`serde` (Rust)，`freezed` (Dart 可选)
- **目标平台**：Android (ARM64)、Windows (x64)

### 3. 架构分层（由上至下）
```
┌─ UI 层 (Flutter) ─────────────────────────────┐
│  页面/视图, 手势, 画布绘制, 工具状态          │
├─ 服务层 (Flutter) ────────────────────────────┤
│  封装 FFI 调用，提供异步方法给 UI             │
├─ 桥接层 (flutter_rust_bridge) ────────────────┤
│  自动生成 Dart 接口与 Rust 实现间的序列化/调用 │
├─ 核心引擎层 (Rust) ───────────────────────────┤
│  PDF 解析 · 标注存储 · 摘录管理 · 知识模型    │
│  全文搜索 · 存储抽象                          │
└─ 系统平台层 ──────────────────────────────────┘
```

### 4. 完整功能模块清单
- **PDF 阅读器**：矢量重绘（永远清晰）、文本选择、搜索、缩略图
- **手写标注**：钢笔/荧光笔（压感）、橡皮擦（对象擦除）、套索移动
- **文字批注**：打字机、便签、下划线/高亮/删除线
- **框选摘录**：矩形框选，提取文字或截图，自动生成卡片
- **摘录与卡片**：PDF/网页摘录 → 富文本卡片，双向跳转，标签管理
- **思维导图**：无限画布，拖拽卡片建树，自动布局，节点-原文联动
- **网页阅读**：内嵌 WebView，JS 提取选中文字，生成网页摘录卡片
- **间隔复习**：基于卡片的 SM-2 复习队列
- **全文搜索**：索引所有卡片、标签、PDF 文本
- **数据同步**：预留模块（未来 CRDT）

### 6. 关键数据流示例（摘录闭环）
1. 用户长按 PDF 文字 → Flutter 获取坐标 → 调用 Rust `extractTextInRect` → 返回文字
2. 用户确认摘录 → 调用 Rust `create_excerpt` → Rust 写入 Excerpt + Card 到 SQLite → 返回卡片 ID
3. Flutter 更新 UI：高亮原文区域、卡片列表刷新
4. 用户将卡片拖入脑图 → 调用 Rust `add_mindmap_node` → 数据库记录关联
5. 全文搜索索引在卡片保存时异步更新（`tantivy`）

### 7. 开发阶段计划（兼职 3-4h/天，约 6-8 个月；全职 3-4 个月）
| 阶段 | 内容 | 周期 |
|------|------|------|
| 0 | 环境搭建与学习（Flutter+Rust+FFI） | 1-2 周 |
| 1 | PDF 渲染 MVP（矢量重绘、文本选择、缩放） | 4-6 周 |
| 2 | 手写批注核心（笔迹、荧光笔、橡皮擦） | 3-4 周 |
| 3 | 文字批注与框选摘录 | 2-3 周 |
| 4 | 摘录系统与笔记卡片（双向联动） | 3-4 周 |
| 5 | 思维导图（无限画布、自动布局） | 3-4 周 |
| 6 | 网页加载与摘录 | 2-3 周 |
| 7 | 全文搜索与间隔复习 | 2-3 周 |
| 8 | 性能优化、跨平台打包 | 2-4 周 |

**启动顺序建议**：从阶段 1（PDF 矢量渲染）开始，这是核心地基。跑通“文字可选、缩放清晰”后，后续模块都是加功能。
