# Phase 2 Spec：节点原地编辑与原地创建

## 背景

当前添加子节点和同级节点依赖弹窗输入标题，打断思维导图编辑流。目标是参考主流思维导图交互：在画布原位置新增节点，并直接进入文本编辑状态。

## 用户故事

- 作为用户，我双击节点后可以在节点原地编辑标题。
- 作为用户，我按 `Tab` 或点击“添加子节点”后，新子节点出现在布局位置，并直接获得焦点进入编辑。
- 作为用户，我按 `Enter` 或点击“添加同级节点”后，新同级节点出现在布局位置，并直接获得焦点进入编辑。
- 作为用户，我按 `Esc` 可以取消本次编辑；新节点不会被自动删除，而是回退到默认标题并保持选中。

## 项目落点

- `lib/src/mindmap/ui/mindmap_controller.dart`
  - 新增 `editingNoteId`、`beginEditing(noteId)`、`commitEditing(noteId, title)`、`cancelEditing(noteId)`。
  - `createChildNode` 和 `createSiblingNode` 支持不传标题时使用默认标题并返回新节点，然后立即进入编辑态。
- `lib/src/mindmap/ui/node_widget.dart`
  - 根据 `editingNoteId` 在原节点位置切换 `Text` 与 `TextField`。
  - 编辑框尺寸遵循当前节点宽高，避免弹出额外对话框。
- `lib/src/mindmap/ui/mindmap_page.dart`
  - 替换添加子节点/同级节点弹窗入口为“创建并编辑”。
  - 保留旧 `AddNodeDialog` 作为暂时兼容入口，后续无引用后删除。

## 交互规则

1. 双击节点进入编辑，文本默认全选。
2. `Enter` 提交；`Shift+Enter` 插入换行（节点支持多行显示）。
3. `Esc` 取消编辑。
4. 编辑失焦提交，空文本不允许覆盖为真正空标题。
5. 新建节点时先写入数据层，再进入编辑；按 Esc 取消时恢复创建时默认标题，不删除节点。
6. 编辑失焦或按 Enter 提交空文本时，恢复默认标题，不允许写入真正空标题，也不自动删除节点。
7. 原地编辑的 TextField 样式与当前节点视觉保持一致（背景色、圆角等）。

## 验收标准

- 添加子节点和同级节点不出现新增标题弹窗。
- 新建节点在画布上可见，并自动进入原地编辑。
- 取消编辑或提交空标题后，新节点仍保留默认标题并保持选中。
- 编辑提交后刷新树和布局，节点仍保持选中。
- 快捷键 `Tab`、`Enter` 与底部按钮行为一致。
