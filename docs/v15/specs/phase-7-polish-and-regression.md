# Phase 7 Spec：整体可用性收尾与回归

## 背景

前六个阶段完成后，需要把基础功能串成稳定体验，避免新增功能互相影响。重点是快捷键、导入导出、持久化、布局/连线边界和文档。

## 用户故事

- 作为用户，我可以连续完成：选择节点、添加子节点、编辑、切换布局、添加标签、创建概要、创建关联线。
- 作为用户，我保存并重新打开导图后，新增数据仍然存在。
- 作为开发者，我能通过测试确认核心功能没有回退。

## 项目落点

- `test/mindmap/domain`：补齐新增 domain 模型测试。
- `test/mindmap` 或 widget 测试目录：覆盖控制器状态流和关键 UI 交互。
- `lib/src/mindmap/export/gurumind_exporter.dart`、`lib/src/mindmap/import/gurumind_data_converter.dart`：本轮需支持关联线、概要、标签的导入导出。
- `docs/v15/walkthrough.md`：记录最终交付功能、验证命令和已知限制。
- `docs/v15/known_issues.md`：记录框架内部概要等未完成功能。

## 回归场景

1. 拖动模式下选择节点，然后创建子节点并编辑。
2. 两侧布局切到左侧、右侧、框架式布局，再切回两侧。
3. 长标题节点添加标签后，父子连线和关联线仍贴边。
4. 多选连续兄弟节点创建概要，切换左右布局后概要位置正确。
5. 删除带有关联线、概要、标签的节点，不产生孤儿数据或绘制异常。
6. 导入已有 Gurumind 数据后，原有导图仍能打开；新增字段缺失时使用默认值。

## 验证命令

- `flutter analyze`
- `flutter test test/mindmap`
- 如新增 Rust 存储接口，运行对应 Rust/FRB 生成与测试命令，并在实施计划中固定命令名称。

## 交付文档

- `docs/v15/walkthrough.md`：交付说明。
- `docs/v15/known_issues.md`：如果存在未完成的兼容项，单独记录。
- 必要时更新 `CONTEXT.md` 或 `docs/adr/`，说明新增的“关联线/概要/标签”领域概念。

## 验收标准

- 所有阶段的关键路径可以串联操作。
- 分析和测试命令没有新增失败。
- 文档说明清楚哪些能力已完成、哪些能力属于后续增强。
