# v16.4 Development Specification — Markdown 所见即所得即时渲染

> **版本目标：** 在现有 `LivePreviewController` 单 TextField 架构上，补齐思源笔记级别的 Markdown 渲染效果和交互能力，包括图片内联渲染、链接可点击、代码块语法高亮、表格渲染、数学公式、Mermaid 图表，以及图片/附件拖拽插入。

---

## 一、版本概述

### 1.1 背景

v16.3 完成了浮动卡片编辑器的核心功能，卡片编辑器处于可用状态。`LivePreviewController` 已实现 Obsidian Live Preview 风格的基础即时渲染（标题、粗体、斜体、代码、链接、删除线、任务列表、分割线、引用）。但仍有大量 Markdown 元素仅仅渲染为文本，缺乏真正的渲染效果和交互能力。

v16.4 专注于在**不改变单 TextField 架构**的前提下，将所有 Markdown 元素（图片、代码块、表格、数学公式、Mermaid、链接、附件）升级为真实的所见即所得渲染。

### 1.2 架构策略：混合渲染（方案 B）

核心思路：**TextField 内占位符保持长度不变量 + Stack Overlay 层渲染真实 widget**

```
LivePreviewCardBody
  └── Stack
      ├── TextField (LivePreviewController.buildTextSpan → 字符占位)
      └── Positioned widgets (图片/代码块/表格/公式/Mermaid)
```

- `LivePreviewController.buildTextSpan` 解析到复杂元素时，用等长透明占位符替代
- `PlaceholderTracker` 维护占位符位置 → widget 的映射
- `CardOverlayRenderer` 在 Stack 层渲染真实 widget，位置与占位符对齐

## 二、Phase 1 — 图片内联渲染

### 2.1 LivePreviewController 变更

在 `_InlineKind.image` 分支中：

- 图片 URL 为本地路径：注入透明占位字符（`\u2800` 布莱叶盲文空格），长度等于 `![alt](url)` 原始长度
- `_renderInline` 中图片 span 的 `_emitInlineSpan`：改为生成 `PlaceholderSpan` 标记，而非纯 TextSpan
- 返回前做长度不变量的断言检查：透明占位不改变字符总量

### 2.2 PlaceholderTracker（新增）

```dart
class PlaceholderTracker {
  /// 占位符信息
  class PlaceholderInfo {
    final String id;           // uuid
    final int lineIndex;       // 行号
    final int charOffset;      // 行内字符偏移
    final int length;          // 占位长度
    final String type;         // 'image' | 'codeblock' | 'table' | 'math' | 'mermaid'
    final String rawMarkdown;  // 原始 markdown 源
  }

  List<PlaceholderInfo> _placeholders = [];

  void rebuild(String markdown);   // 重新解析 markdown，重建占位符列表
  int totalPlaceholderChars();     // 占位字符总数
  PlaceholderInfo? findAtOffset(int absoluteOffset); // 根据字符偏移查占位符
}
```

### 2.3 CardOverlayRenderer（新增）

- 接收 `PlaceholderTracker` 的快照
- 使用 `GlobalKey` 获取 TextField 中每行的 `RenderBox` 位置
- 用 `CompositedTransformFollower` / `Stack.positioned` 在占位符位置叠加 widget
- 行位置变化（滚动、插入/删除文本导致换行）时重新定位

### 2.4 ImageRenderer（新增）

```dart
class ImageRenderer extends StatelessWidget {
  final String imagePath; // 本地绝对路径
  final double maxWidth;  // 卡片最大宽度

  // Image.file 加载，等比缩放，最大高度 400px
  // 加载失败显示 [broken] 文本
}
```

### 2.5 Toolbar 更新

- `MdToolbarAction.image` 当前回调 `onInsertImageRequested` → 改为直接调用 `file_picker`，选择后复制到 `{document_dir}/assets/images/{uuid}.ext`，插入 `![alt](path)`
- 新增 `file_attachment_service.dart`：统一的文件复制/路径管理

## 三、Phase 2 — 链接可点击 + 附件插入

### 3.1 LinkHandler（新增）

- Ctrl+Click（`HardwareKeyboard.instance.isControlPressed` + `onTap`）检测光标是否在链接范围内
- 在 `LivePreviewController.buildTextSpan` 中，链接的 `[text](url)` 的 `url` 部分添加 `TapGestureRecognizer`
- 点击后：
  - 网络 URL（`http://` / `https://`）：`url_launcher` 打开
  - 本地路径：`Process.start` 或 `open_file` 包打开
- 焦点在 TextField 内时与正常编辑不冲突（Ctrl+Click 只在按下 Ctrl 时生效）

### 3.2 附件插入

- Toolbar 新增"插入附件"按钮（`Icons.attach_file`）
- 选择文件 → 复制到 `{document_dir}/assets/files/{uuid}_{original_name}`
- 在光标处插入 `[filename](assets/files/uuid_original_name)`
- 拖拽支持：`Draggable` / ` desktop_drop` 包检测拖入文件
  - 图片文件（`.png/.jpg/.gif` 等）→ 自动 `![]()`
  - 其他文件 → `[filename]()`

## 四、Phase 3 — 代码块 + 语法高亮

### 4.1 LivePreviewController 变更

- 围栏代码块 `\`\`\`lang` / `~~~lang` 检测
- 光标行为：
  - 光标在围栏范围内（`\`\`\`` 行到闭合 `\`\`\`` 行之间）：块内行渲染为源码（等宽 + 半透明背景色），围栏标记淡化
  - 光标不在代码块范围内：全部内容替换为透明占位符，Overlay 层渲染高亮 widget
- 语言标识（````dart` 中的 `dart`）解析传递给 `CodeBlockRenderer`

### 4.2 CodeBlockRenderer（新增）

- 使用 `flutter_highlight` 包（引用 marktext-plus 的 `highlight` 依赖）
- 渲染为 `Container` + 等宽字体 `SelectableText` + 语法着色
- 样式：深色背景 + 行号（可选）+ 边框圆角
- 最大高度 500px，超出可滚动

## 五、Phase 4 — 表格渲染

### 5.1 LivePreviewController 变更

- 管道表格语法检测：以 `|` 开头的连续行判定为表格块
- 表头分隔行（`|---|---|`）检测
- 表格整体替换为透明占位符
- 列对齐检测：`:---` 左对齐、`:---:` 居中、`---:` 右对齐

### 5.2 TableRenderer（新增）

- 使用 Flutter 原生 `Table` widget
- 表头行加粗 + 底部分隔线
- 支持列对齐
- 最大宽度约束，超出水平滚动

## 六、Phase 5 — 数学公式

### 6.1 LivePreviewController 变更

- 行内公式 `$...$`（非 `$$`）检测：公式内容用等宽风格，不替换占位符
- 块级公式 `$$...$$` 检测：整体替换为透明占位符
- 公式内容提取（去除首尾 `$`/`$$`）

### 6.2 MathRenderer（新增）

- 使用 `flutter_math_fork` 包（与 marktext-plus 一致）
- 行内公式：在 TextSpan 中用 `WidgetSpan` + 小字号渲染
- 块级公式：Overlay 层渲染 `Math.tex()` widget

## 七、Phase 6 — Mermaid 图表

### 7.1 LivePreviewController 变更

- `\`\`\`mermaid` / `\`\`\`mmd` 围栏检测
- 整体替换为透明占位符
- 语言标识 `mermaid` 传递给 `MermaidRenderer`

### 7.2 MermaidRenderer（新增）

**直接引用 marktext-plus 的 Mermaid 实现**（`code/lib/ui/editor/mermaid/`）：

| 源文件 | 用途 |
|--------|------|
| `mermaid.dart` + `mermaid_parser.dart` | 入口解析 |
| `models/diagram.dart` | 图表数据模型 |
| `parser/flowchart_parser.dart` 等 | 图表类型解析器 |
| `painter/flowchart_painter.dart` 等 | 图表 CustomPainter |
| `widgets/mermaid_diagram.dart` | 图表 widget |

引用方式：将 `mermaid/` 目录整体复制到 `lib/src/mindmap/ui/cards/live_preview/rendering/mermaid/` 或作为独立目录。不做 API 重构，只做路径适配。

## 八、关键风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| **占位符 ↔ widget 位置偏移** | 图片/代码块渲染位置错位 | `CompositedTransformFollower` 绑定到 `RenderBox`；文本变更时通过 `addPostFrameCallback` 重新定位 |
| **TextField 重建导致 Overlay 闪烁** | 每次 build 重绘 | `PlaceholderTracker.rebuild` 做 diff，只更新变化的占位符 |
| **大量图片导致内存问题** | 卡片页内存超限 | 图片用 `cached_network_image` / 本地文件缓存，超出 5 张 LRU 淘汰 |
| **Mermaid 图表重新实现成本** | Phase 6 时间不可控 | **直接引用** marktext-plus 的完整实现，不做重构 |
| **flutter_math_fork 与现有依赖冲突** | pub get 失败 | 已在 v16.3 中验证过兼容性 |
