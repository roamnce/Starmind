# 思维导图卡片式布局复刻设计文档 (v13)

本设计文档详细定义了复刻两个思维导图框架卡片布局（亮色和暗色）的技术方案。

---

## 1. 目标与实现原则

- **精准复刻**：1:1 还原截图中的组件边距、圆角、背景色、分割虚线、标签徽章及整体视觉层次感。
- **高保真 SVG 连线**：在 HTML 页面中使用绝对定位的 SVG 元素，通过 JavaScript 动态计算节点锚点，绘制完美的贝塞尔连线。
- **交互与微动画**：
  - 卡片 Hover 时有微发光与上移效果。
  - 点击节点支持 Active 高亮。
  - 支持折叠与展开功能（折叠后子节点隐藏，SVG 连线动态重算）。
  - 支持画板的缩放 (Zoom) 与平移 (Pan) 基础交互，模拟真实的思维导图软件体验。

## 2. 亮色卡片布局设计 (`card_layout_light.html`)

### 2.1 UI 结构与 CSS 设计
- **主框架卡片** (`.main-card`)：
  - 背景：`#ffffff`，边框 `1.5px solid #a7d6f5` (软天蓝色)。
  - 圆角：`12px`，带柔和的阴影 `box-shadow: 0 10px 30px rgba(167, 214, 245, 0.15)`。
  - 顶部 Header：背景 `#bfe2fa`，字体加粗，下边缘有一条 `#a7d6f5` 的虚线 (`border-bottom: 1.5px dashed`)。
- **分支区域 - 顶部**：
  - 父节点：白色胶囊卡片，灰色边框 `#e2e8f0`，内容为 "卡片"。
  - 右侧子节点垂直堆叠，包含三张彩色卡片：
    - **Teal 卡片**：背景 `#9ad3df`，边框/虚线 `#74b9c7`。
    - **Green 卡片**：背景 `#cfead4`，边框/虚线 `#a2d3ab`。
    - **Orange 卡片**：背景 `#fde3c3`，边框/虚线 `#e9be8a`。
  - 连接线：由父节点右中心连接到子节点左中心。
- **分支区域 - 底部**：
  - 外部嵌套卡片：背景 `#f8fafc`，边框 `#e2e8f0`，圆角 `8px`。
  - 内部两个子卡片并排：背景 `#ffffff`，边框 `#e2e8f0`，有中间虚线分隔，内部文本为 "卡片"。

### 2.2 SVG 连线逻辑
- 页面加载和窗口大小改变时，调用 `drawLightConnectors()`。
- 获取父卡片 `.card-parent` 右侧中点的绝对坐标 `(px, py)`。
- 获取三个子卡片 `.child-card` 左侧中点的绝对坐标 `(cx, cy)`。
- 在 SVG 中绘制三条 `path`，其曲线控制点使它们形成自然的 `S` 形曲线。

## 3. 暗色卡片布局设计 (`card_layout_dark.html`)

### 3.1 UI 结构与 CSS 设计
- **背景画布** (`.viewport`)：
  - 背景色：`#0c0e12`。
  - 细网格背景：使用 CSS `linear-gradient` 实现 `20px * 20px` 的正方形暗网格。
- **主框架卡片** (`.main-card`)：
  - 背景：`#171a21`，边框 `1.5px solid rgba(255, 255, 255, 0.08)`。
  - 顶部悬挂根节点 (`.root-badge`)：半挂在主框架的左上角，颜色为深蓝灰 `#354556`，内含 "AI配音"，以及带折叠状态的减号图标。
- **分支区域 - 左侧（红色分区）**：
  - 外框：半透明红色边框 `rgba(246, 86, 86, 0.2)`，极淡红色背景 `rgba(246, 86, 86, 0.03)`。
  - 标题徽章：红色背景 `#f65656`，文字为白色 "常用平台"。
  - 内部包含：
    - "国内平台" 节点（带有二级嵌套子节点 "minimax"、"千问" 和下方 "豆包"）。
    - "国外平台" 节点。
- **分支区域 - 右侧（蓝色分区）**：
  - 外框：半透明蓝色边框 `rgba(112, 125, 244, 0.2)`，极淡蓝色背景 `rgba(112, 125, 244, 0.03)`。
  - 标题徽章：蓝紫色背景 `#707df4`，前置黄色小旗帜🚩图标，内容为 "分支主题3"。
  - 内部包含：
    - "小说" 节点。

### 3.2 节点布局与渲染方式
- 国内平台子节点的 "minimax" 与 "千问" 采用 `display: flex; flex-direction: row; gap: 8px;` 并排。
- "豆包" 位于第二行，通过块级排版单独占一行，形成与截图完全一致的布局。

## 4. JS 连线算法与交互机制

### 4.1 SVG 贝塞尔曲线算法
曲线从起点 `(x1, y1)` 绘制到终点 `(x2, y2)`，公式为：
```javascript
const dx = Math.abs(x2 - x1) * 0.5;
const d = `M ${x1} ${y1} C ${x1 + dx} ${y1}, ${x2 - dx} ${y2}, ${x2} ${y2}`;
```
对于国内平台指向 "minimax"/"千问" 的分支，将连线从国内平台引出到分支，再分别连接到子节点。

### 4.2 折叠与展开 (Collapse / Expand)
- 给每个带有 `(-)` 按钮的节点添加 `click` 事件。
- 点击时切换 `.collapsed` 类。
- 隐藏被折叠的子 DOM 节点。
- 重新调用 `drawConnectors()` 重新计算所有 SVG 路径的起点与终点。

## 5. 验证计划

- **浏览器兼容性验证**：在主流 Chrome/Edge/Firefox 下验证布局的稳定性和 SVG 连线计算是否精确无偏移。
- **窗口自适应**：缩放窗口或改变容器尺寸时，SVG 线段应当平滑且无延迟地重新计算定位。
- **高阶美学审查**：仔细对照截图的配色与圆角比例，确保视觉效果的高保真。
