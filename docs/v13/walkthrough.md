## 2. 复刻细节与技术亮点

### 2.1 亮色模式卡片布局 (`card_layout_light.html`)
- **视觉设计**：
  - 1:1 复刻天空蓝顶部标题栏 ("时间")，辅以软天蓝色边框与精美的虚线分隔线。
  - 父卡片与三个子卡片采用精致的 CSS Flexbox 树状层级排版。
  - 三个子卡片拥有专属的马卡龙背景色及相应的彩色虚线与锚点（粉蓝 Teal、粉绿 Green、粉橙 Orange）。
  - 下方完美复刻了带阴影的“卡片”大外部容器卡片和两张并排的白色子卡片。
  - 整体包含毛玻璃微发光背景装饰球。
- **连线与交互**：
  - 加载时使用 Javascript 动态获取输出锚点与输入锚点坐标，在 SVG 画布上绘制精细的贝塞尔曲线。
  - 窗口缩放 (resize) 时自适应重算，确保线条紧贴锚点。
  - 任意卡片点击后带有高亮蓝色发光边框，点击空白处可消除激活态。

### 2.2 暗色模式卡片布局 (`card_layout_dark.html`)
- **视觉设计**：
  - 采用极客暗黑风设计，背景配有精美的 CSS 细小微亮正方形网格（20px * 20px）和蓝紫色毛玻璃微发光光晕。
  - 根节点徽章 ("AI配音") 挂靠在主框架的左上角。
  - 左右两侧分区分别采用半透明红褐色 (`rgba(246, 86, 86, 0.03)`) 和蓝紫色 (`rgba(112, 125, 244, 0.03)`) 的发光边框外盒。
  - 子节点如 "国内平台" 采用纯黑卡片与灰色细边框。下一级 "minimax" 与 "千问" 采用并排药丸胶囊小卡片，"豆包" 则独占下一行，完美契合截图比例。
  - "分支主题3" 内置高清晰度 🚩 图标。
- **折叠与展开交互**：
  - 完美实现节点多级折叠。点击分区徽章或特定节点（国内平台、根节点）旁的 `[−]` / `[+]` 按钮，对应的子节点会动态隐藏。
  - 折叠后自动清除并隐藏对应的连线；重新展开时连线自适应重绘。
  - 点击节点支持激活高亮发光边框效果。
