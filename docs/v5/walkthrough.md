该原型复刻了设计图中的深色高端网格背景、发光背景霓虹光圈，并严格实现了用户指定的顶部控制面板、大纲模式说明、右下角导航雷达、以及底部导图工具栏的全部新交互。

## 2. 核心功能与技术实现

### 2.1 结构调整与图标更新
- **面包屑栏调整**: 移除了原 AI 配音左侧的 UI “主页” 按钮。
- **窗口控制按钮**: 最顶部右侧的 “置顶” 按钮已移除，保留 “分屏” 与 “设置”。
- **大纲模式切换**: 在撤销重做后面添加了 “切换到大纲模式” 按钮（大纲样式 SVG 图标），并为该按钮在代码中附带了 `data-desc` 说明属性，描述其用于支持从导图一键切换到类似幕布的大纲笔记编辑视图，以便后续模型解析与开发。

### 2.2 浮动与弹窗优化交互 (关于、大快捷键、小地图)
- **关于弹窗 (i 图标)**: 点击后在左下角悬浮框展现该导图的统计信息。**弹窗位置整体向右平移至 80px，彻底避免了与左侧缩放控制条的重叠遮挡**。
- **居中快捷键大弹窗 (? 图标)**: **点击后直接从屏幕中央以流畅的缩放（scale）动画弹出**。该面板尺寸（520px x 600px）与布局设计完全遵循用户上传的“快捷键”截图，包含：
  - 顶栏：“取消”（左侧蓝色）、“快捷键”标题（居中）、“重置”（右侧红色）与“保存”（灰色）。
  - 全局快捷键组：分屏模式、折叠/恢复左侧标签页、折叠/恢复右侧标签页、交换左右标签页、切换焦点到对侧标签页、关闭标签页、窗口截图。
  - 结构与节点快捷键组：添加子节点、添加同级节点、折叠/展开分支、编辑选中节点、删除选中节点。
  - 底部附带“编辑全局快捷键”的蓝色按钮提示。
- **小地图面板 (雷达图标)**: 点击后在右下角弹出 “小地图（导航雷达）”，小地图以微缩色块显示脑图的节点分布。并且**视口框 (minimap-viewbox) 会随着脑图的平移和缩放比例进行自适应的动态位移和尺寸调整**，实现超高保真度的雷达跟踪。

### 2.3 顶部更多操作菜单 (More Dropdown)
- **更多操作弹窗 (`...` 按钮)**: 点击后在 `...` 按钮正下方滑出带有上指向三角形的黑金质感磨砂下拉菜单。
- 包含选项：导出文件、生成闪卡、演示模式，以及三个开关操作：**“隐藏左上按钮组”**、**“隐藏左下按钮组”**与**“隐藏底部按钮组”**。点击对应选项可动态显示/隐藏对应的工具栏或控制条。

### 2.4 底部导图工具栏交互 (Toolbar Action)
- **拖动工具**: 激活时，按住鼠标左键可平移画布（默认模式）。
- **套索工具**: 点击开启并显示激活背景色。**在套索激活时，画布平移功能被禁用，鼠标拖动背景会生成虚线多选框 (selection-box) 批量选中框体内的导图节点**。
- **节点添加工具**: 分别对应 “添加子节点 (Tab)” 与 “添加同级节点 (Enter)”，并包含按键联动交互。
- **节点扩展**: 包含 “创建概要”、“创建边框”、“关联线（建立连线）”、“创建标签” 以及 “添加节点笔记” 的交互模拟。
- **导图布局切换**: 点击导图布局按钮，会在**布局按钮正上方居中浮出**下拉菜单。**弹出位置经过精密偏移计算，确保不会与底部工具栏重合，也不会与任何按钮栏重叠**。支持选择两侧布局/左侧布局/右侧布局。选择左侧布局时，脑图层级方向整体向左（`row-reverse`），且**贝塞尔连线重绘引擎会自动判别节点的水平相对位置，智能反向绘制圆滑贝塞尔曲线**。
- **锁定编辑**: 点击锁定按钮激活。当锁定后，其它工具被禁用（变灰并禁用点击），节点不可进行高亮选中、折叠、平移或缩放。

## 3. 手动验证指南

1. **运行原型**:
   双击或在浏览器中打开 [D:/starmind/prototype/思维导图页面/index.html](file:///D:/starmind/prototype/思维导图页面/index.html)。
2. **验证左下角与居中弹窗**:
   - 点击 `i` 按钮，确认 “关于” 统计浮窗在关于按钮右侧弹出，无重叠。
   - 点击 `?` 按钮，确认精美的 “快捷键” 列表模态框从屏幕中心缩放浮现，遮罩与取消/保存功能完整。
   - 点击 “雷达” 按钮，确认右下角 “小地图” 浮窗弹出；平移与缩放脑图时，黄色视口框同步平滑跟踪。
3. **验证更多下拉菜单**:
   - 点击右上角操作栏中的 `...` 按钮，确认弹出黑色三角下拉菜单。
   - 点击 “隐藏左下按钮组”，确认左侧垂直控制条消失；点击 “隐藏底部按钮组”，确认底部工具栏消失。可通过下拉菜单再次点按恢复显示。
4. **验证布局切换**:
   - 点击底部布局按钮，确认布局下拉菜单在其正上方居中悬浮出现，无任何层级重叠。
   - 选择 “左侧布局”，确认脑图平稳移到根节点左侧，且贝塞尔连线完美地向左弯曲重绘。
5. **验证锁定模式**:
   - 点击最右侧 “锁” 按钮，确认画布和节点不再响应 Hover，且底部工具栏除锁按钮外全部变灰。再次点击锁按钮恢复正常。
