# 思维导图页面高保真原型设计方案 (v5.0)

本设计文档旨在指导“思维导图页面”高保真原型图的设计与开发，确保其在视觉风格和交互体验上与已有原型（首页、PDF批注页面）保持高度一致，实现完美的“像素级”还原与平滑的用户交互。

---

## 1. 视觉与布局设计

原型采用响应式单页 Web 结构，通过绝对定位与 CSS Flexbox 实现层级布局，自适应浏览器窗口。

### 1.1 配色系统 (Color Palette)
使用符合 StarMind 原型系统的暗色系风格：
- `--bg0`: `#0c0a07` (主背景色，深黑色)
- `--bg1`: `#141008` (次背景色，暗黄褐色)
- `--bg2`: `#1c1710` (暗卡片底色)
- `--border`: `rgba(255,220,140,0.08)` (微光边框)
- `--border-h`: `rgba(255,220,140,0.18)` (悬浮高亮边框)
- `--accent`: `#c8841a` (金黄色高亮，用于选中态)
- `--accent-bg`: `rgba(200,132,26,0.15)` (高亮背景)
- `--tp`: `rgba(255,248,235,0.9)` (一级文字颜色)
- `--ts`: `rgba(255,248,235,0.52)` (二级文字颜色)
- `--tm`: `rgba(255,248,235,0.28)` (说明文字颜色)
- 脑图分支特定色：
  - `常用平台` 红色系: `rgba(224, 88, 88, 0.85)`
  - `分支主题3` 紫色系: `rgba(138, 92, 242, 0.85)`
  - `连接线` 渐变色: 动态连接线使用渐变或高对比色描边。

### 1.2 页面布局组件
1. **顶部 Tab 栏 (Tab Bar)**:
   - 首页 Tab、2026考研数学高数 Tab、**AI配音 Tab (激活态)**。
   - 激活态 Tab 为圆角卡片，深青褐色渐变边框，带微光。
   - 右侧包含窗口控制按钮：分屏、置顶、设置等。
2. **顶部路径面包屑栏 (Breadcrumb Bar)**:
   - 左侧操作组：`<-`, `->`, `Star`, `Bookmark`, `Home`, 面包屑 `AI配音`。
   - 右侧操作组：撤销、重做、树状布局、更多菜单、侧栏切换。
3. **主画布区 (Workspace Canvas)**:
   - 20px 网格背景。
   - 三个发光霓虹光圈 (`.orb`) 浮动于底层。
   - 居中的脑图渲染容器，支持平移和缩放。
4. **左侧浮动缩放条 (Zoom Panel)**:
   - 垂直圆角磨砂玻璃面板，浮动于左下角。
   - 按钮组：`+`, `100%`, `-`, 分割线, `i`, `?`, `脑图图标`。
5. **底部浮动操作条 (Toolbar)**:
   - 水平圆角磨砂玻璃面板，浮动于底部中央。
   - 功能按钮：光标、评论、节点增加、同级/子级、分支、套索、属性、标签、语音、文件、锁定。

## 2. 脑图节点与连接线实现

脑图使用 DOM 渲染节点卡片，以确保文字排版质量及交互的简易性；底层叠加全屏 `<svg>` 画布，用以动态绘制贝塞尔连接曲线。

### 2.1 脑图节点数据结构
使用一个简易的层次化 JSON 数据驱动节点渲染与折叠状态控制：
```javascript
const mindData = {
  id: "root",
  text: "AI配音",
  type: "root",
  children: [
    {
      id: "branch1",
      text: "常用平台",
      type: "accent-red",
      children: [
        {
          id: "branch1-1",
          text: "国内平台",
          type: "dark",
          children: [
            { id: "leaf1", text: "minimax", type: "dark" },
            { id: "leaf2", text: "千问", type: "dark" },
            { id: "leaf3", text: "豆包", type: "dark" }
          ]
        },
        {
          id: "branch1-2",
          text: "国外平台",
          type: "dark"
        }
      ]
    },
    {
      id: "branch2",
      text: "分支主题3",
      type: "accent-purple",
      hasFlag: true,
      children: [
        { id: "leaf4", text: "小说", type: "dark" }
      ]
    }
  ]
};
```

### 2.2 连接线渲染算法
使用 SVG 贝塞尔曲线，由 JS 动态计算父节点与子节点之间的端点位置：
- **起点 (sx, sy)**: 父节点卡片右边缘中点 `x = parent.left + parent.width`, `y = parent.top + parent.height / 2`。
- **终点 (tx, ty)**: 子节点卡片左边缘中点 `x = child.left`, `y = child.top + child.height / 2`。
- **控制点偏移量**: `dx = (tx - sx) * 0.45`。
- **路径数据**: `d="M ${sx} ${sy} C ${sx + dx} ${sy}, ${tx - dx} ${ty}, ${tx} ${ty}"`。
- 监听画布缩放、窗口大小调整以及折叠/展开动作，实时重绘连接线。

## 3. 交互与动效设计

1. **节点展开与折叠**:
   - 一级节点右侧在悬浮时显示 `[-]` 或 `[+]` 切换按钮。
   - 点击折叠时，子节点应用 `scale(0.8)` 与 `opacity: 0` 动画淡出并设置 `display: none`；SVG 连接线伴随折叠动作平滑消隐或重新计算。
2. **画布整体缩放与平移 (Pan & Zoom)**:
   - 挂载鼠标拖动事件于画布背景上，实现鼠标拖拽平移整个脑图节点。
   - 监听左下角 `+`、`-` 按钮及鼠标滚轮事件，调整脑图渲染容器的 CSS `transform: scale(...)` 属性。
3. **节点激活选中 (Active Selection)**:
   - 点击任意节点会给该节点添加 `.active` 类，添加金色高亮边框和流光阴影。
   - 点击空白处取消所有节点的选中态。
4. **按钮悬停微动效 (Hover micro-interactions)**:
   - 所有按钮、标签和工具栏图标在 Hover 时伴随背景半透明加深、边框微光和轻微上移 (`transform: translateY(-1px)`) 动画。
